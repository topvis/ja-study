# 常用“特殊”五段动词整理

在日语中，动词词尾为「る」且前一假名落在 **イ段** 或 **エ段** 时，绝大多数属于 **一段动词**。

但是，有一批高频动词虽然外形符合一段动词特征，**实际活用规则却是五段动词**。这类动词在日常交流与考试中极其常见，需要特别记忆。

::: tip 快速辨别法则（ナイ形反推法）

- **五段动词**：词尾变成对应 **ア段假名 + ない**（如：帰る → 帰**ら**ない）
- **一段动词**：直接 **去る + ない**（如：食べる → 食**べ**ない）

:::

---

## 一、 前一假名在 イ段（〜いる）

以下动词前一假名位于 **イ段**，但按照 **五段活用**（变ア段 + ない）：

| 汉字/词汇 | 假名   | 词义         | 否定式（ナイ形） | 常用例句 / 备注                 |
| :-------- | :----- | :----------- | :--------------- | :------------------------------ |
| **知る**  | しる   | 知道、了解   | 知ら**な**い     | 何も知らない (什么也不知道)     |
| **走る**  | はしる | 跑、奔跑     | 走ら**な**い     | 公園を走る (在公园跑步)         |
| **入る**  | はいる | 进入、加入   | 入ら**な**い     | 部屋に入る (进入房间)           |
| **切る**  | きる   | 剪、切、断开 | 切ら**な**い     | ハサミで切る (用剪刀剪)         |
| **要る**  | いる   | 需要         | 要ら**な**い     | ビザは要らない (不需要签证)     |
| **限る**  | かぎる | 限定、限于   | 限ら**な**い     | これに限らない (不限于此)       |
| **散る**  | ちる   | 凋谢、散落   | 散ら**な**い     | 桜が散る (樱花凋谢)             |
| **握る**  | にぎる | 握、捏       | 握ら**な**い     | 手を握る (握手)                 |
| **焦る**  | あせる | 焦急、着急   | 焦ら**な**い     | 焦らないでください (请不要着急) |
| **弄る**  | いじる | 摆弄、捣鼓   | 弄ら**な**い     | スマホを弄る (摆弄手机)         |

## 二、 前一假名在 エ段（〜える）

以下动词前一假名位于 **エ段**，同样按 **五段活用**：

| 汉字/词汇 | 假名     | 词义             | 否定式（ナイ形） | 常用例句 / 备注       |
| :-------- | :------- | :--------------- | :--------------- | :-------------------- |
| **帰る**  | かえる   | 回家、归去       | 帰ら**な**い     | 家に帰る (回家)       |
| **喋る**  | しゃべる | 说话、聊天       | 喋ら**な**い     | 日本語を喋る (讲日语) |
| **減る**  | へる     | 减少             | 減ら**な**い     | 体重が減る (体重减少) |
| **蹴る**  | ける     | 踢               | 蹴ら**な**い     | ボールを蹴る (踢球)   |
| **滑る**  | すべる   | 滑、滑倒         | 滑ら**な**い     | 足が滑る (脚滑)       |
| **照る**  | てる     | 照耀、阳光照射   | 照ら**な**い     | 陽が照る (阳光照耀)   |
| **練る**  | ねる     | 推敲、揉（面团） | 練ら**な**い     | 対策を練る (推敲对策) |
| **茂る**  | しげる   | 繁茂、茂盛       | 茂ら**な**い     | 木が茂る (树木茂盛)   |

## 三、 同音 / 同形易混淆对比

::: warning 注意区分同音词部分词汇发音相同或写法相近，但所属动词类别不同，活用方式也完全不同：

:::

### 1. 「いる」

- **要る**（需要）：**五段动词** → 要ら**な**い / 要り**ま**す
- **居る**（在/存在）：**一段动词** → 居**な**い / 居**ま**す

### 2. 「かえる」

- **帰る**（回家）：**五段动词** → 帰ら**な**い / 帰り**ま**す
- **変える / 代える**（改变/替换）：**一段动词** → 変え**な**い / 変え**ま**す

### 3. 「きる」

- **切る**（切/剪）：**五段动词** → 切ら**な**い / 切り**ま**す
- **着る**（穿衣服）：**一段动词** → 着**な**い / 着**ま**す
